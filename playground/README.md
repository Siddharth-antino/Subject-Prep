# Subject Prep web app

React + Vite interface for spoken subject preparation. Choose a subject, talk with the coach, follow live captions, request hints and review your progress. Typed messages are optional. There are no notes pages or coding workspace.

Use `npm run setup`, `npm run dev` and `npm run check` from the repository root. The conversation is available at `/` and `/prepare`; retired page addresses return to preparation. The backend is in `../server` and uses `/api/preparation` for session and voice tools.

See the [root README](../README.md) for ports, credentials, memory and storage settings.
